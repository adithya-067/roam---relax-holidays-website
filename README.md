# Roam & Relax Holidays

A modern, responsive travel website built for **Roam & Relax Holidays**, designed to showcase destinations and travel packages while allowing customers to directly enquire through WhatsApp and email.

## Live Website

https://www.roamandrelaxholidays.com

## Features

- Destination and travel package browsing
- Detailed package pages with day-by-day itineraries
- Responsive design for desktop and mobile
- Customer enquiry form
- Supabase-powered enquiry storage
- WhatsApp enquiry integration with pre-filled messages
- Business contact and enquiry information
- Custom domain deployment
- Automated deployment through Vercel and GitHub

## Tech Stack

- **Next.js**
- **TypeScript**
- **React**
- **Tailwind CSS**
- **Supabase**
- **Vercel**
- **Git & GitHub**
